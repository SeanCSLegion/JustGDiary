## 0. 快速定位

### 0.1 一句话

这是一个**日记数据本地存储、无账号、无云同步**的日记应用：以“日历中的一天”为中心，写/读/编辑当天的若干片段；
另外提供全文搜索、按地点聚合的足迹、以及本地 `.jdiary` 备份导入导出。

### 0.2 屏幕地图

```
启动
 └─ 首页（日记） ── 点某天 / 点日记卡 / 搜索命中 / 足迹地点 ──► 日记阅读页
      │                                                     └─ 点铅笔 / 点卡片 ─► 日记编辑页
      ├─ 足迹
      ├─ 搜索
      └─ 设置
```

| 屏幕 | 入口 | 退出方式 | 是否全屏 |
| --- | --- | --- | --- |
| 首页（月/周/年） | 默认 Tab；点底栏/侧栏「日记」 | 切 Tab；进入日记页 | 否，保留导航 |
| 日记阅读页 | 首页某天、日记卡、搜索命中、足迹地点、深链、通知 | 左上返回 / 系统返回 | **是**（盖住底栏） |
| 日记编辑页 | 阅读页顶栏铅笔（仅当天）、阅读页点卡片、空态入口 | 保存、放弃、返回 | **是** |
| 搜索 | 底栏/侧栏「搜索」；`justdiary://search`；快捷方式「搜索日记」 | 切 Tab | 否 |
| 足迹 | 底栏/侧栏「足迹」 | 切 Tab | 否 |
| 设置 | 底栏/侧栏「设置」 | 切 Tab | 否 |
| 图片全屏预览 | 阅读页/编辑页点图片 | 点关闭 / 返回 | 是，沉浸式 |
| 启动错误态 | 开库/迁移失败 | 重试 | 是 |

### 0.3 本文里的“今天”

“今天”不是 `LocalDate.now()` 直接得到的自然日，而是由设置项 **`新一天的开始时间`（`day_start_hour`，默认 04:00）** 折算出的日记日：

```
本地时间 00:00–03:59  → 归入前一天
本地时间 04:00–23:59  → 归入当天
```

默认 `day_start_hour = 4` 时，11 月 13 日凌晨 02:00 写的内容属于 **11 月 12 日**。
首页、阅读页、搜索、通知、备份导入后的换日重算都使用同一条规则。

### 0.4 当前版本与语言

- 应用名：`一页时光`（不随语言变化）。
- 界面语言：跟随系统 / 中文 / English。
- 默认主题：跟随系统；支持浅色 / 深色；支持 Material You 动态取色（Android 12+）。
- 默认提醒：开启，21:00；默认周起始：周一；默认自动记录时间：开；默认自动插入地点：开；默认允许修改历史日记：**关**。

## 1. 应用级结构与交互

### 1.1 启动与首帧

```
Application.onCreate
  ├─ 初始化 AppContainer（懒加载）
  ├─ 应用一次 AppCompat DayNight（仅进程启动，不重建 Activity）
  ├─ 清理 14 天以前的编辑器草稿
  └─ MainActivity.onCreate
       ├─ 解析深链 / 调试开关
       ├─ 启动 SettingsViewModel.bootstrap（异步）
       │    ├─ 应用语言
       │    ├─ 打开数据库 / 迁移 / 重建搜索索引
       │    ├─ 清理孤儿图片（草稿引用受保护）
       │    └─ 建通知渠道 + 排提醒
       └─ setContent：先按当前设置渲染界面，不阻塞首帧
```

启动失败（数据库无法打开、迁移失败）时**不会**展示空日记本，而是进入「无法打开日记本」错误页：

- 标题：`无法打开日记本`
- 说明：`你的日记可能仍然安全。请先重试，不要急着卸载；如果一直失败，可以用 .jdiary 备份恢复。`
- `查看详情` / `隐藏详情`：显示或隐藏底层 SQLite 错误。
- `重试`：重新跑启动序列。

### 1.2 导航与自适应

| 宽度 | 导航 | 说明 |
| --- | --- | --- |
| `< 600dp` | 底部 `NavigationBar` | 四项：日记 / 足迹 / 搜索 / 设置 |
| `≥ 600dp` | 左侧 `NavigationRail` | 同上，四项竖排，带文字 |

- 默认落在「日记」Tab。
- 每个 Tab 的 ViewModel 在**第一次打开时**创建，之后保持存活；切 Tab 不会重建页面状态。
- 全屏日记页打开时，导航栏被完全盖住；关闭后回到之前的 Tab。
- 主题切换**不重建 Activity**；语言切换仍走系统官方 `setApplicationLocales`，会重建一次 Activity，重建前已对齐窗口底色。
- 窄屏手机锁竖屏；平板（`sw600dp`）允许旋转。
- 横屏/宽屏（内容宽 ≥ 548.5dp 且宽 > 高）启用左右分栏：首页左月历右当日内容，搜索左筛选右结果，足迹趋势与地点并排。

### 1.3 主题、字体与语言

- 主题三档：`跟随系统` / `浅色` / `深色`；动态取色开关（默认开）。
- 字号跟随系统字体缩放，各角色有不同上限；日历日号、编辑器段落、格式栏高度会按字号档适配。
- 语言三档：`跟随系统` / `中文` / `English`；**农历只在中文界面显示**，英文界面不显示农历/干支，避免日格被挤成两行。
- 应用内语言影响日期/星期/月份的格式；小时制仍跟随设备设置（12/24 小时）。

### 1.4 权限

| 权限 | 申请时机 | 拒绝后的行为 |
| --- | --- | --- |
| 位置（精确/模糊） | 打开「自动插入地点」、新建片段需要定位、或阅读页点「重新获取位置」 | 不崩溃；地点留空，可稍后重试；设置页保留权限行 |
| 通知（Android 13+） | 首次启动（提醒开启且未授权）先弹说明，再弹系统授权 | 不反复弹；设置页「通知权限」行可再次打开系统设置/申请 |
| 存储 | **不需要**：导入导出走 SAF，选图走 Photo Picker | — |

没有账号、云同步、后台联网上传；地点只保存在本机。

### 1.5 深链、通知、快捷方式

| 入口 | 目标 |
| --- | --- |
| `justdiary://editor?dayKey=YYYY-MM-DD` | 打开指定日期的阅读页 |
| `justdiary://editor` | 打开“今天”的阅读页（打开时按 `day_start_hour` 现算） |
| `justdiary://search` | 切到搜索 Tab |
| 通知点按 / 动作「写日记」 | 同 `justdiary://editor`，打开今天的阅读页 |
| 长按图标「写今天」 | 同 `justdiary://editor` |
| 长按图标「搜索日记」 | 同 `justdiary://search` |

通知行为：

- 每天在设置的时间检查“今天是否已写”；已写则跳过今天。
- 使用 `WorkManager` 一次性任务，**不是精确闹钟**；Doze 下可能延迟几分钟。
- 时区/系统时间改变后自动重排。
- 通知小图标是白色剪影；文案为「写日记提醒 / 今天还没有写日记，花几分钟记录一下吧」。

### 1.6 数据与备份（应用级约定）

- 全部数据在应用私有目录：SQLite 数据库 + `filesDir/images` + 草稿目录。
- 系统 Android Auto Backup **关闭**；换机/恢复只走设置页导出的 `.jdiary`。
- `.jdiary` 是标准 zip：`manifest.json` + `db/just_diary.db` + `images/<name>`。
- 导入是**单事务**：任一天失败回滚全部数据库；已解出的图片会清理；非法图片路径整包拒绝。
- 导入两种模式：`跳过已有日记` / `覆盖已有日记`。
- 导入的 `day_start_hour` 与本机不同时，先询问是否按备份时刻重算现有日记；取消则保留当前设置。

### 1.7 全局失败/空态

- 启动开库失败：全屏错误页 + 重试。
- 备份导出/导入失败：设置页对话框提示；不会留下半套数据。
- 提醒投递失败：只记日志，不打断日记编辑。
- 图片解码失败：编辑器中提示「无法读取这张图片，请换一张重试。」；列表中显示占位图标。

## 2. 首页（日记）

首页是**整屏三态日历**：月态 → 周态 → 年态。冷启动恒为「今天 + 月态」，不记忆上次停留态。
数据变更 / 设置变更（语言、主题、周起始、`auto_time`、换日时刻、导入备份）会重置回「今天 + 月态」。

### 2.1 月态（默认）

```
┌──────────────────────────────────────┐
│ [ ‹ 2026年 ]                 [ 今天 ] │  64dp 悬浮胶囊行
│                                      │
│  十一月                              │  72dp 大标题
│  一  二  三  四  五  六  日           │  30dp 星期栏
│ ───────────────────────────────────  │
│  26 27 28 29 30 31  1                │
│  廿一 廿二 …                          │  连续月历流
│   2  3  4  5  6  7  8                │
│  …                                   │
└──────────────────────────────────────┘
```

- **左胶囊**：月态显示当前年份（如 `2026年`），点击进入**年态**。
- **右胶囊**：显示相对日或具体日期：
  - 选中日就是今天：`今天`
  - 昨天/明天：`昨天` / `明天`
  - 更远：`N 天前` / `N 天后`
  - 选中日不在当前浏览月：显示具体日期（如 `9月26日`），避免“看着 12 月却写今天”的误导
  - 点击：回到今天；月态会滚到当天，周态会选中今天，年态先 morph 回当月
- 日期格：
  - 今天：`primary` 描边圆
  - 选中日：`primary` 实心圆 + `onPrimary` 日号
  - 有日记：日号下方短横线
  - 未来日期：`onSurfaceVariant`，仍可点
  - 相邻月日期：淡显，**不可点**（连续流里属于相邻月块）
- 中文界面显示农历/节气；英文不显示。
- 点任意**当月**日期：选中该日并立即进入**周态**（不是阅读页）。
- 上下滑动：连续翻月（跨月不整窗重建，相邻月会滚动进入）。
- 无障碍开启时：每个当月日期有一个可聚焦、可点击的节点（日期 + 今天/选中 + 有/无日记），并额外提供「前一天 / 后一天 / 上一月 / 下一月 / 上一年 / 下一年」自定义动作；**无障碍关闭时仍走 Canvas，不建逐日节点**。

> [home-month-light.png](ui-audit/home-month-light.png)（月态）、[home-week-light.png](ui-audit/home-week-light.png)（周态）、
> [home-year-light.png](ui-audit/home-year-light.png)（年态）、[home-landscape.png](ui-audit/home-landscape.png)（平板分栏）。

### 2.2 周态

```
┌──────────────────────────────────────┐
│ [ ‹ 十一月 ]                [ 今天 ]  │
│  9月22日 周一              丙午年…    │  日期行 + 农历靠右
│ ───────────────────────────────────  │
│  22  23  24  25  26  27  28          │  周条
│  …                                   │
│ ───────────────────────────────────  │
│  9月24日 周三              丙午年…    │  当日标题行
│  09:41 · 浦东新区 · 上海市            │  当日片段卡片
│  正文…                                │
│  [ 继续写日记 ]                       │
└──────────────────────────────────────┘
```

- 左胶囊显示当前月份名，点击回月态。
- 右胶囊同月态，回到今天。
- 周条横向滑动翻周；点其他日期只改变选中日，点**已选中的日期**打开阅读页。
- 点未来日期：Snackbar「这一天还没到，不能写日记」。
- 当日面板：
  - 标题：完整日期 + 农历（中文）
  - 有片段：按时间顺序显示片段卡片（时间/地点/正文/图片/引用/列表/待办预览）
  - 今天且有片段：底部按钮「继续写日记」→ 打开**阅读页**
  - 今天且空：图标 + `这一天没有留下日记。` + 按钮「写日记」→ 打开**阅读页**（当前实现；阅读页再点顶栏铅笔进入编辑）
  - 未来且空：`这一天还没有到来。`，没有写入口
  - 历史且空：`这一天没有留下日记。`，没有写入口
- 点片段卡片 → 打开该日阅读页。

> ⚠️ **当前实现与旧设计文档的差异**：首页所有“写日记 / 继续写日记”入口从 R35 起都先进入**阅读页**，
> 再由阅读页顶栏的铅笔进入编辑；不是直接打开编辑器。本文按当前实现描述。

### 2.3 年态

```
┌──────────────────────────────────────┐
│ 2026年                       丙午马年 │
│ ┌────────┐ ┌────────┐ ┌────────┐     │
│ │  一月   │ │  二月   │ │  三月   │     │  3 × 4 迷你月
│ │ 1 2 3… │ │ …      │ │ …      │     │
│ └────────┘ └────────┘ └────────┘     │
│ …                                    │
└──────────────────────────────────────┘
```

- 无左胶囊；右胶囊仍在（回今天）。
- 每张卡片是一个整体点击目标，点任意迷你月 → 缩放 morph 回**月态**并停在该月。
- 迷你月里的选中日用实心圆、今天用描边圆；有日记有短横线。
- 系统返回键从年态回月态（不等同退出应用）。

### 2.4 横屏 / 平板分栏（首页）

- 内容宽 ≥ 548.5dp 且宽 > 高时，首页为左右分栏：
  - 左：月历（紧凑标题 34dp + 星期栏 26dp），只能上下滑翻月、点日期
  - 右：选中日的当日面板（标题行含日期、农历、`今天` 胶囊）
- 分栏下**没有年态、没有周态**；进入分栏时无动画收回月态。
- 分栏下点日期只更新右栏，不进入周态。
- 平板竖屏保持单栏、日历限宽 640dp 居中。

### 2.5 首页手势 / 动画 / 状态

| 手势 | 行为 |
| --- | --- |
| 月态上下滑 | 连续翻月；松手后吸附到整月 |
| 月态点日期 | 选中 + 进周态（竖屏） |
| 月态点左胶囊 | 进年态 |
| 周态左右滑 | 翻周 |
| 周态点左胶囊 | 回月态 |
| 年态点迷你月 | 回月态并跳到该月 |
| 点右胶囊 | 回今天（按当前形态处理） |
| 系统返回 | 年态/周态先回月态；月态交还系统 |

- morph 进行中禁用日期/胶囊/返回等输入，避免状态与画面不一致。
- 数据/设置变化时重置回「今天 + 月态」；这是有意行为，不记忆上次停留态。

## 3. 日记阅读页

### 3.1 入口与整体结构

入口：首页某天、首页日记卡、搜索命中、足迹地点、深链、通知。
全屏路由，盖住底部/侧边导航。

```
┌──────────────────────────────────────┐
│ ←      [搜索] [写日记] [分享]         │  TopAppBar 64dp
│                                      │
│ ┌──────────────────────────────────┐ │
│ │ 9月15日 周二    [今天]            │ │  Hero 卡
│ │ 09:41 · 2 个片段                  │ │
│ │ 浦东新区 · 上海市 · 中国           │ │
│ └──────────────────────────────────┘ │
│ ┌──────────────────────────────────┐ │
│ │ 09:41                             │ │  条目卡
│ │ 浦东新区 · 上海市 · 中国           │ │
│ │ 正文 / 引用 / 列表 / 待办 / 图片…  │ │
│ └──────────────────────────────────┘ │
│ …                                    │
│ [悬浮页内搜索栏（点搜索后出现）]       │
└──────────────────────────────────────┘
```

> 参考截图：[read-today-dark.png](ui-audit/r27/read-today-dark.png)、[read-rich-dark.png](ui-audit/r27/read-rich-dark.png)。

### 3.2 顶栏三态

| 形态 | 左侧 | 右侧 |
| --- | --- | --- |
| 阅读 | `←` 返回 | `搜索`（激活时 primary 高亮）· `写日记`（**仅当天**）· `分享` |
| 多选 | `×` 退出多选 | 标题「已选择 N 项」+ `删除`（error 色，空选禁用） |
| 编辑 | `←` 返回 | `插图` · `放弃修改` · `保存`（primary） |

- 「写日记」只在天出现；历史日期不能新增，只能改已有片段（且需设置允许）。
- 点顶栏空白处收键盘。

### 3.3 Hero 卡

- 常驻，空的一天也有。
- 内容：日期标题 + 今日胶囊 + 首条片段时间 + `N 个片段` + 首条地点。
- 没有片段时显示 `这一天没有留下日记。`。
- 整卡合并为一条无障碍语义。

### 3.4 条目卡

- 每张卡对应一个**编辑块**，按 `start_time_utc` 升序。
- 抬头：时间（`auto_time` 关闭时隐藏）+ 地点（最多两行）。
- 正文：逐段落渲染；支持大标题/小标题/正文/引用/列表/待办/图片。
- 交互：
  - 点整卡（含正文）→ 编辑该片段（历史日期需允许修改；否则弹只读提示）。
  - 长按 → 进入多选并选中该卡。
  - 多选态点卡 → 切换选中。
  - 点待办项 → 直接切换完成状态（不进入编辑）。
  - 点图片 → 全屏预览（双击/点按）。
  - 无障碍自定义动作：`编辑` / `删除`；删除只删这一条并弹确认框，不进多选态。
- 选中卡：2dp `primary` 描边 + 左侧勾选圈。

### 3.5 页内搜索

- 顶栏搜索图标切换显示；搜索栏**悬浮在内容上方**，计数与步进键始终可见。
- 输入 150ms 防抖后计算命中；命中与高亮共用 `DiarySearch.findMatches`。
- 命中样式：当前命中 `primary` 实底反转字；其余命中 `primaryContainer` 底。
- 计数：`第 n / 共 m`；`上一个 / 下一个` 在命中间跳转并滚动到对应片段。
- 无命中文案：`无匹配`。
- 关闭搜索会清空关键词、命中与滚动目标。

### 3.6 多选与删除

- 长按卡片进入多选；顶栏变成「已选择 N 项」+ 删除。
- 点其他卡片切换选中；点 `×` 退出多选。
- 删除先弹确认框：`将删除选中的 N 个编辑块，删除后不可恢复。`
- **没有删除撤销**；确认后才执行。
- 删除后停留阅读态；当天没有片段时 Hero 显示空态。

### 3.7 分享长图

- 点顶栏分享 → 打开底部分享面板：
  - 生成中：进度圈 + `正在生成分享图…`
  - 生成完成：预览图 + 文件名/尺寸 + `分享…` / `保存到相册`
- `分享…` 调系统 Sharesheet；`ACTION_SEND` 无接收方时 Snackbar `没有可用的分享应用。`
- `保存到相册` 成功 Snackbar `已保存到相册`，失败 `保存失败，请稍后重试。`
- 关闭面板后临时文件延迟 30 秒清理（不会立刻删掉接收方还在读的文件）。
- 分享图上的地点按设置「分享位置精度」降级；精确地点与街道不会进入分享图。

### 3.8 空态 / 历史 / 未来

- 空的一天：Hero 始终在，卡片区没有条目。
- **当前阅读页空态只有 Hero 卡 + 顶栏铅笔**；没有正文中央的“写日记”按钮。
  （首页空态按钮会先打开阅读页，再点顶栏铅笔进入编辑。）
- 历史日期：没有顶栏「写日记」；点已有卡片时，如果「允许修改 / 删除历史日记」关闭，弹只读提示。
- 未来日期：不允许新增；从周条点未来日会提示「这一天还没到，不能写日记」。
- 图片缺失/加载中：显示占位图标，不改变布局。

## 4. 日记编辑页

### 4.1 入口

- 阅读页顶栏铅笔（**仅当天**）→ 新建片段。
- 阅读页点已有条目卡 → 编辑该片段。
- 首页空态「写日记」/「继续写日记」不会直接进编辑；先到阅读页。

新建片段 vs 编辑已有片段：

| | 新建片段 | 编辑已有片段 |
| --- | --- | --- |
| 时间 | 点「写日记」那一刻 | 原片段 `start_time_utc` |
| 地点 | 可重新获取 | 只读，不重新获取 |
| 保存按钮 | 保存并退出 | 保存 |
| 历史日期 | 不允许新建 | 需允许修改历史日记 |

### 4.2 结构

```
┌──────────────────────────────────────┐
│ ←        [插图] [放弃修改] [保存]     │
│ ┌──────────────────────────────────┐ │
│ │ 09:41                            │ │  时间胶囊（auto_time 开）
│ │ 浦东新区 · 上海市 · 中国  [精度]  │ │  地点行
│ │                                  │ │
│ │ 开始记录这一刻的想法…              │ │  编辑区
│ │                                  │ │
│ └──────────────────────────────────┘ │
│  [段落样式 ▼] [居中] | [列表] [引用] [待办] | [B] [I] [S] [U] │
└──────────────────────────────────────┘
```

- 编辑卡占满剩余高度；底部格式栏钉在键盘上方，不遮光标。
- 时间胶囊：`自动记录时间` 关闭时隐藏，但数据层仍记录 `start_time_utc`。
- 地点行：
  - 定位中：`位置获取中…`
  - 失败：`未获取到位置`，新建片段可点「重新获取位置」
  - 已有地点：显示地点；点「精度」菜单可调整分享/记录精度
  - `自动插入地点` 关闭：不显示地点行
- 占位文案：新建 `开始记录这一刻的想法…`；编辑已有 `修改这段内容…`。

> 参考截图：[edit-with-keyboard.png](ui-audit/r28/edit-with-keyboard.png)、[edit-style-menu.png](ui-audit/r28/edit-style-menu.png)。

### 4.3 格式栏

固定 9 个按钮，横向可滚动：

| 按钮 | 作用 |
| --- | --- |
| 段落样式 | 打开菜单：大标题 / 小标题 / 正文 |
| 居中 | 仅正文行可点；列表 / 引用 / 待办 / 图片行置灰 |
| 列表 | 切换整行无序列表；空项回车结束 |
| 引用 | 切换整行引用；空引用行回车结束 |
| 待办 | 切换整行待办；空项回车结束 |
| 粗体 / 斜体 / 删除线 / 下划线 | 行内样式，可叠加；有选区作用选区，无选区作用于后续输入 |

- 段落样式按钮高亮只认大标题 / 小标题，引用行不会点亮。
- 居中与列表 / 引用 / 待办 / 图片互斥。
- IME 组合输入期间整栏禁用，避免 span 被输入法覆盖。
- 格式栏不抢焦点、不收键盘；段落样式菜单从格式栏上方弹出。

### 4.4 回车与格式规则

| 场景 | 当前行为 |
| --- | --- |
| 列表 / 待办有内容 + 回车 | 新行继续同一标记 |
| 列表 / 待办空项 + 回车 | 结束列表，当前行变正文 |
| 大标题 / 小标题 + 回车 | 新行继承同一样式 |
| 引用有内容 + 回车 | **新行继续引用**（跟随 iOS） |
| 空引用行 + 回车 | 吃掉按键，当前行结束引用（光标回列首） |
| 居中空行 + 回车 | 吃掉按键（居中空行不堆叠） |
| 居中正文 + 回车 | 新行不继承居中 |
| 段落行首 + 回车 | 上方空行归属纠正：引用→正文、标题保留、居中不留；被顶下去的行接回样式 |

### 4.5 插图

- 顶栏图片按钮 → Photo Picker（无需存储权限）。
- 导入中：格式栏上方轻量进度 `正在读取图片…`，不抢焦点。
- 导入失败：Snackbar `无法读取这张图片，请换一张重试。`
- 落盘：原分辨率 + JPEG q0.95；只有 OOM 才回退 2048px。
- 图片**独占一行**；插入后光标落在图片下面那一行。
- 编辑页图片按列宽等比显示；点图可全屏预览。

### 4.6 保存 / 放弃 / 返回

- 保存：
  - 新片段未获取到地点（`auto_loc` 开）→ 弹「未获取到位置」：`仍然保存` / 取消
  - 保存时跨过换日线 → 弹「跨日编辑提示」，确认内容将保存到目标日期
  - 失败 → 弹「保存失败」
  - 成功 → 回阅读页；当天有内容时显示
- 放弃修改：
  - 有改动 → 弹「放弃修改？」→ 确认后回到进入编辑时的内容/阅读态
- 返回：
  - 多选 → 退出多选
  - 编辑且有未保存内容 → 弹「退出编辑」
  - 编辑且内容为空 → 直接回阅读态（不关页）
  - 阅读 → 关闭页面

### 4.7 草稿

- 编辑内容每 250ms（防抖）落盘为草稿；Activity 进入后台 `ON_STOP` 再强制落盘一次。
- 进程被杀/配置变更后重新进入同一天/同片段，可恢复内容 + 选区。
- 保存、放弃、空内容退出时清草稿；超过 14 天的草稿启动时清理。
- 草稿引用的图片不会被“孤儿图片清理”误删。

## 5. 搜索

### 5.1 结构（竖屏）

```
┌──────────────────────────────────────┐
│ 搜索                        [N 条]    │  PageHeader
│ ┌──────────────────────────────────┐ │
│ │ 🔍 搜索日记内容…              ×  │ │  输入框
│ └──────────────────────────────────┘ │
│ ┌ 时间范围 ────────────────────────┐ │
│ │ [全部时间] [本周] [本月] [今年] [自定义] │
│ │ 地点                              │ │
│ │ [全部地点] [未记录地点] [选择地点] │ │
│ └──────────────────────────────────┘ │
│ [关键词胶囊 ×] [条件胶囊 ×] …  [清除全部] │
│ ────────────────────────────────────  │
│ 日期徽标 · 时间                      │
│ 摘要…                                │
│ 高亮片段…                            │
│ ────────────────────────────────────  │
│ [加载更多]                            │
└──────────────────────────────────────┘
```

### 5.2 搜索输入

- **输入时不实时查询**；打字只更新输入框。
- 按键盘搜索/回车（`onSearch` / `onDone` / `onGo`）后才把关键词变成胶囊并查询。
- 输入框聚焦时右侧出现「取消」：清空输入并收键盘。
- 输入框为空但有已提交关键词时，清空输入不会改变条件；「清除全部条件」才会清空。
- 每条生效条件显示为可单独移除的胶囊；最右是「清除全部条件」。

### 5.3 筛选

- 时间：全部时间 / 本周 / 本月 / 今年 / 自定义。
  - 自定义打开 `DateRangeSheet`：开始、结束、确定、清除。
  - 时间筛选是本地 `day_key` 字符串区间。
- 地点：
  - 全部地点
  - 未记录地点（只匹配没有地点信息的片段）
  - 选择地点：底部面板，按日记数量排序的候选；面板内搜索走 SQL `LIKE`，不是只过滤前 20 条。
  - 选中国家/地区后成为条件胶囊；可单独移除。
- 时间与地点是**交集**。

### 5.4 结果

- 顶部右侧显示 `找到 N 条日记`（无结果不显示计数）。
- 每行：本地化日期徽标 + 时间 + 摘要 + 命中片段（`primaryContainer` 底色高亮，不改字色/字重）。
- 点击整行 → 打开该日阅读页。
- 分页 200 条；有更多时显示「加载更多」。
- 状态：
  - 索引重建中：`正在准备搜索索引…` + 进度条（与“无结果”严格区分）
  - 查询中：顶部进度条 + 骨架行
  - 查询出错：`搜索出错` + 错误信息 + `重试`
  - 未输入条件：`搜索你的日记` / `输入关键词，或选择时间与地点筛选`
  - 有条件无结果：`没有找到匹配的日记` + `清除全部条件`

### 5.5 横屏 / 平板

- 左栏 340dp 常驻：页头 + 搜索框 + 筛选卡；
- 右栏结果列表；
- 分栏下不显示条件摘要行（左栏 chip 已表达）。

- 聚合在后台 `Dispatchers.Default` 执行；重新聚合时旧内容保留，顶部显示 2dp 进度条。

## 8. 横切行为与视觉规则

### 8.1 主题与颜色

- Material 3 语义色；动态取色开时用系统壁纸色，关闭时回落到品牌蓝。
- 背景/卡片/引用/待办等都用 `MaterialTheme.colorScheme` 角色，不硬编码颜色。
- 深色/浅色切换不重建 Activity；窗口底与状态栏/导航栏图标同步。

### 8.2 字体缩放

- 跟随系统 `fontScale`；各角色有上限，避免标题/日号无限放大。
- 日历日号、农历字号按格高计算；格式栏高度随字号调整。
- 编辑/阅读正文列宽上限 660dp，页面左右 16dp；两处共用同一列宽公式。

### 8.3 无障碍

- 日历月态在无障碍开启时挂逐日节点与前后日/月/年动作；正常模式走 Canvas。
- 阅读页卡片整卡一条语义 + 「编辑 / 删除」自定义动作。
- 待办勾选、图片预览、分享按钮等有 contentDescription。
- 统计卡、柱状图合并为单条语义，避免逐数字刷屏。
- 已知未做：TalkBack 真人逐条走查、48dp 触控目标全面量测（P2-11/P2-12）。

### 8.4 图片

- 插图：Photo Picker → 原分辨率 + JPEG q0.95，去掉 GPS/机型/时间，只烘入方向；OOM 才回退 2048px。
- 显示：首页当日面板 480px 缩略图；阅读/编辑 1600px；分享预览按宽度采样。
- 内存缓存 96MB；系统内存紧张时清空。
- 编辑器中图片行独占一行；阅读页点图可全屏预览。

### 8.5 数据模型

- 一天 = `day_key`，由本地时间和 `day_start_hour` 折算。
- 一天包含若干编辑块；每块有 `start_time_utc`、地点/精度、`content_json`。
- `content_json` 的段落样式：`body` / `title` / `heading` / `quote` / `list` / `todo` / `image`。
- 行内样式：粗体 / 斜体 / 删除线 / 下划线；居中是段落属性（不跨行继承）。
- 列表/待办共用 items；待办有 done 数组。
- 图片 src 形如 `images/img_<ms>.jpg`，只允许 `images/` 下的安全 basename。
- 搜索使用 FTS5（不可用时退化为 LIKE）；页内搜索与结果高亮共用 `DiarySearch.findMatches`。

### 8.6 手势与动画

- 首页月↔周、月↔年 morph；动画期间禁输入；减弱动态效果时缩短为 180ms 交叉淡入。
- 阅读页不下拉刷新；没有侧滑删除。
- 编辑器没有撤销/重做（已确认不做）；回滚只靠「放弃修改」和磁盘草稿。

### 8.7 关键尺寸 / 阈值（当前实现）

## 9. 当前已知边界与待办（避免误解）

### 9.1 明确不做

- 账号 / 云同步 / 多设备自动同步。
- Android Auto Backup（已关闭）。
- 删除撤销（只有删除前确认）。
- 编辑器撤销 / 重做。
- 从其他 App 分享文字/图片进日记（P1-8 未选）。
- 相机直拍、多图批量插入、桌面小组件、搜索历史、应用锁（P3 可选）。

### 9.2 仍在待办

- **P2-3** 月→周动画约 80fps、新月份首块绘制 17–19ms，待单独性能轮。
- **P2-6** 大文件拆分（`HomeScreen` / `MonthFlow` / `EditorModel` / `SettingsScreen` / `SpannableBridge`）。
- **P2-11 / P2-12 / P2-13** TalkBack 真人走查、48dp 触控目标、三项真机视觉走查（分享深色 / 平板分享面板 / 图片行光标）。
- 编辑 vs 阅读逐像素目前只有**正文单段**基线，允许 8% 抗锯齿/letterSpacing 差异；列表/待办/引用未纳入。

### 9.3 已知视觉/平台限制

- 编辑器引用段的**右边距**挂不上（`Spannable` 没有右边距 span），是唯一三处对不齐的地方。
- 语言切换仍会重建 Activity（官方 `setApplicationLocales`）；主题切换不会。
- 通知不是精确闹钟，Doze 下可能晚几分钟。
- 备份导入是本地文件操作；损坏/恶意包整包拒绝，不做“清洗后继续”。
- 图片存储不保留 PNG 透明：统一 JPEG，截图/贴纸的 alpha 会变黑底（与 iOS 存储形状一致）。
