# R40 · 真机走查（MEIZU 21 / Android 16 / 1080×2340 / 440dpi）

本轮设备任务：P2-3 morph 性能、P2-11 TalkBack、P2-12 48dp 触控目标、P2-13 三项视觉走查。

## P2-3 morph 性能

- 测量：`-morph-log`，AOT 编译后连续 3 轮；当时用临时探针 `ScrollProf.blockDraw` 记录月份块绘制（探针已在 R44 删除）。
- 结果：月→周 97.8–100.7fps（最长 24ms），周→月 117.5–119.4fps（最长 8–16ms）；
  新月份块首帧 6.8ms（改前 19.1ms）；周→月退出瞬间整窗 8 块重录 38.9ms → 2 块 ~7ms。
- 截图：`01-month.png` / `02-week.png` / `03-morph-mid.png`；原始日志 `morph-log.txt`。

## P2-11 TalkBack（焦点/语义走查）

- 开启 TalkBack（系统教程跳过）后抓取无障碍树：
  - 月态：43 个日期节点，`content-desc` 带“日期 + 今天/选中 + 有/无日记”状态
    （如“11月14日 周六 · 今天 · 已选中 · 无日记”），见 `12-talkback-month.xml`；
  - 设置：10 个行级可点节点；开关行 `checked` 状态正确，相邻标签无重复停靠，
    见 `13-talkback-settings.xml`；
  - 格式栏 9 键均有 `content-desc`；“设置”标题等静态文本可聚焦。
- 2.0× 字体：首页与设置页无裁切（`10-home-font2.png` / `11-settings-font2.png`）；
  设置页副标题在 2.0× 会换行，行高仍容纳，未压到分隔线。
- 说明：本轮为真机焦点/语义走查，未做人工听觉确认（语速/语气需人耳）。

## P2-12 48dp 触控目标（uiautomator 实测）

| 目标 | 实测 bounds | 结论 |
| --- | --- | --- |
| 月态日格 | 56dp × 72dp（末行 51dp） | ≥48 |
| 周态日格 | 80dp × 80dp | ≥48 |
| 设置行 | 376dp × 56dp | ≥48 |
| 搜索时间/地点胶囊 | 106dp × 48dp | =48 |
| 顶栏图标 | 48dp × 48dp | =48 |
| 底部导航 | 80dp × 80dp | ≥48 |
| 格式栏按钮 | 40–47.6dp × 48dp | 宽 <48，**有意例外** |

格式栏 9 键一行在 393dp 宽屏上物理上放不下 9×48dp（432dp）。设计 §3.3 选择
“一行优先、按钮 40dp 宽 × 48dp 高”，代码注释已记录；若要严格 48×48，只能横滑或换行，
属产品/设计取舍，本轮不改。
