# 09 · 前四屏验收清单（交给用户测试用）

> 用途：**照着走一遍就能判断"有没有大问题"**。每条都写清了"应该看到什么"，
> 不符合的就是缺陷，直接说第几条即可。
>
> 范围：地基（方向锁定 / 分栏）+ 首页 + 设置页 + 搜索页 + 足迹页。
> **日记页不在本轮**（按约定等这份清单走完再动）。
>
> 装包：`app/build/outputs/apk/debug/app-debug.apk`（或 `./gradlew installDebug`）。

---

## 0. 先确认环境

- [ ] 手机竖屏**无论如何转都不会横过来**（把自动旋转打开、把手机横过来试）
- [ ] 平板可以自由旋转；横屏时出现**左右分栏**（左日历 / 右当日内容）
- [ ] 平板横屏进来时自动停在**月态**（横屏不提供年历入口，也没有周态）

---

## 1. 首页

### 1.1 三态切换
- [ ] 顶栏左胶囊显示「2026年」→ 点它 → **整屏 morph 进年历**（12 张迷你月）
- [ ] `九月` 那张卡片有轻微底色高亮（回答"我在哪个月"）
- [ ] 今天那一格是**实心圆**；有日记的日子下面有一条**短横线**；两者可以同时出现
- [ ] 在年历里点任意月份 → **morph 回月态**并停在该月
- [ ] 年历里按**系统返回键** → 回月态（**不应闪退**）
- [ ] 月态点任意一天 → **整屏 morph 进周态**（只剩一行 + 下方当日内容）
- [ ] 周态按**系统返回键** → 回月态
- [ ] 周态下方只有日期标题行，**没有**「今天」按钮（分栏右栏才有）

### 1.2 翻页（**月态 = 连续月历流**，见 `03-home.md` §8.7.1）

| 视图 | 交互 |
| --- | --- |
| 月 | **无级滚动 + 不吸附**（连续月历流，`MonthFlow.kt`） |
| 周 | 横向翻周（`LazyRow` + 官方吸附） |
| 年 | 上下翻年（手写分页器） |

- [ ] 月态**手指往上拖**：日历**无缝跟着手指走**（1:1，起手 2dp 就跟，不顿挫），
      下一个月的内容**紧接着**上一月的最后一行出现 —— **中间不应有空洞、空白或裁切**
- [ ] 松手后**停在原地、不吸附**（慢拖 / 快甩都不该被"拨回整月起点"）；快甩是
      一段平滑减速后停住，**到点即停、没有回弹**
- [ ] 滑行中**手指按下去**：内容立刻停在当前帧、随即跟手（不是等动画跑完才响应）
- [ ] 拖到两端（1900-01 / 2100-12）是**橡皮筋**，松手弹回（不是硬墙）
- [ ] **月份大标题与星期栏钉在顶部不动**，只是**换字**：大标题 = **占视口最多**的那一个月
- [ ] 每个月 1 号上方显示的**月份小标签**，**居中压在 1 号的正上方**（不是左对齐）
- [ ] 月份小标签紧贴在**分割线上方**（不额外占一行高度），
      与上一个月最后一行**留出一小段空档**（"以小月份的上方为限"）
- [ ] 一屏正好 **6 行 = 一个月**（行高与 iOS 同一条尺子）：6 行月正好铺满、
      5 行月底下露下个月第一行
- [ ] 年态同样跟手，相邻年份滑进来（**不应该拖出空白**）
- [ ] 周态竖直拖没有反应，横向拖才翻周；横拖时**左右邻周**都在（**不应留白**）
- [ ] 翻月之后右上胶囊从「今天」变成具体日期（如「9月26日」），点它回到今天
- [ ] 顶栏左胶囊在**月态读作「返回年历」**、周态读作「返回月历」（TalkBack）

### 1.2.2 三态切换的"从哪来到哪去"（2026-09-27 重点）

- [ ] **在半月位置**（不是整月起点）点某一天 → 进周态：那一行**平滑地**升到星期栏下方，
      其余行上/下移出屏幕，当日内容从下面顶上来
- [ ] 周态返回月态：**同一行回到它原来的位置**（月视图的滚动位置**一点都不变**）
- [ ] 月 → 年：连续流从"当前那张月网格"缩进年历卡片（**不应跳回该月静止位置**）
- [ ] 年 → 月（点迷你月）：网格从卡片长出来，**下一个月的日期立即出现**（不等动画结束）
- [ ] 反复"月→周→月→年→月"之后，月视图仍在原来的滚动位置

### 1.2.1 排版（按 iOS 参考图重排；2026-09-27 行高改为对齐 iOS）
- [ ] 行高 = `(区高 − 标题槽 − 星期栏) / 6`（iPhone 94pt / 本机 ~105dp），一屏一个月
- [ ] **农历完整可见**，没有下半截被切掉（尤其把系统字号调大之后）
- [ ] 有日记那天的小短横线，**不会让那一格整体比别的格高/低**
- [ ] 日号与农历在分隔线之间**大致居中**

### 1.3 当日内容
- [ ] 空的一天：「这一天没有留下日记。」+ **铅笔图标** + 「写日记」按钮
- [ ] 未来日期：月亮图标 + 「这一天还没有到来。」，**没有**写日记按钮
- [ ] **周态点未来的那一天** → 底部弹一条 Snackbar「这一天还没到，不能写日记」+「知道了」

## 2. 设置页

- [ ] 页面标题「设置」的位置与搜索页、足迹页**完全对齐**（左边距、顶部高度一致）
- [ ] 每一条说明都是**一行**，没有折行的
- [ ] 卡片底部**没有多余留白**（末行文字下方只有一点点）
- [ ] 开关行**整行都能点**（不用非点在开关上），TalkBack 每行只停一次
- [ ] 「版本」那一行**没有箭头**、点了没反应（它不是可点的）
- [ ] 「新一天的开始时间」→ 弹出**底部面板**（不是对话框），当前值带勾
- [ ] 把它从 4:00 改成 2:00：**如果会影响已有日记**，会先弹「改变归属日？有 N 篇…」
  - [ ] 在点「继续」**之前**，行内取值还是旧的
  - [ ] 点「继续」之后取值才变
- [ ] 「提醒时间」→ 底部面板 + Material 表盘
- [ ] 「导出全部日记」→ 系统文件选择器；失败有提示（成功/失败都用「好」关闭）
- [ ] 「导入备份」→ 确认框正文说清了**跳过**与**覆盖**各自的后果，破坏性的「覆盖」在最右且是红色

## 3. 搜索页

- [ ] 五个时间档在**一行里左右滑动**（不是折成两行）
- [ ] 点输入框聚焦 → 右侧**追加「取消」**按钮；点它清空并收键盘
- [ ] 有内容时输入框内出现 ✕ 清除
- [ ] 输入关键词后，**未回车的输入**也会作为一枚可撤销的胶囊出现在条件行
- [ ] 条件行的每一枚胶囊点 ✕ 都能单独撤掉；「清除全部条件」一次清空
- [ ] 命中词只有**底色**高亮，字色与粗细不变
- [ ] 「自定义」→ 底部面板：
  - [ ] 输入 `2026-9-1`（**不补零**）能正常应用（不会变成"没有结果"）
  - [ ] 输入 `2026-2-30`（不存在的日期）→ 输入框变红 + 一行红字 + **「确定」置灰**
  - [ ] 两端写反（开始晚于结束）能自动纠正，不报错
- [ ] 「选择地点」→ 底部面板：
  - [ ] 面板里的搜索框**真的能过滤**（随便打几个字母，列表应变空并显示「暂无地点数据」）
  - [ ] 「未记录地点」是一个独立选项
- [ ] 结果行：左边日期徽标、右边时刻；点整行进日记页
- [ ] 平板横屏：左栏筛选常驻、右栏结果

---

## 4. 足迹页

- [ ] 顶部一行：`全部`｜有内容的年份｜`自定义`，**可以左右滑动**
- [ ] **默认选中「全部」**；点了年份或自定义之后，**同时只有一个被选中**
- [ ] 年份里**只有真的有内容的年份**（点任何一年都一定有结果，不会点出空白）
- [ ] 「自定义」胶囊上**不显示具体日期**（只看得到「自定义」三个字）
- [ ] 统计卡 5 格（省市 / 城市 / 国家 / 片段 / 天数），数值**单行**不换行
- [ ] 趋势图：只有 **≥ 2 个年份**时才出现；网格是 **5 档**；某年为 0 时画一条**底边**
- [ ] 地点清单：国家 → 省 → 市 三级可展开；每行高度够（不会误触到相邻行）
- [ ] 把时间范围设成一段**没有记录**的区间：**统计卡照常显示 0**（不是整页被空态替换），
      年份胶囊消失、只剩「全部 + 自定义」

---

## 5. 跨屏与外观

- [ ] 深色模式：五个页面都没有看不清的文字，选中态与未选中态可区分
- [ ] 系统字号调到 **1.3×**：没有文字被裁切、没有按钮被挤出屏幕
- [ ] 在别处（日记页 / 导入备份）改过日记后回到**首页**，应回到「今天 + 月态」
- [ ] 搜索页在日记内容变化后重新查一次（结果不会停留在旧数据）
- [ ] 切换语言（设置 → 语言）：日期与时刻格式跟着**应用内语言**，不出现中英夹心
