## 1. 首页

### 1.1 三态切换
- [ ] 顶栏左胶囊显示「2026年」→ 点它 → **整屏 morph 进年历**（12 张迷你月）
- [ ] `九月` 那张卡片有轻微底色高亮（回答"我在哪个月"）
- [ ] 今天那一格是**实心圆**；有日记的日子下面有一条**短横线**；两者可以同时出现
- [ ] 在年历里点任意月份 → **morph 回月态**并停在该月
- [ ] 年历里按**系统返回键** → 回月态（**不应闪退**）
- [ ] 月态点任意一天 → **整屏 morph 进周态**（只剩一行 + 下方当日内容）
- [ ] 周态按**系统返回键** → 回月态
- [ ] 周态下方只有日期标题行，**没有**「今天」按钮（分栏右栏才有）

### 1.2 翻页（**月态 = 连续月历流**，见 `03-home.md` §8.7.1）

| 视图 | 交互 |
| --- | --- |
| 月 | **无级滚动 + 不吸附**（连续月历流，`MonthFlow.kt`） |
| 周 | 横向翻周（`LazyRow` + 官方吸附） |
| 年 | 上下翻年（手写分页器） |

- [ ] 月态**手指往上拖**：日历**无缝跟着手指走**（1:1，起手 2dp 就跟，不顿挫），
      下一个月的内容**紧接着**上一月的最后一行出现 —— **中间不应有空洞、空白或裁切**
- [ ] 松手后**停在原地、不吸附**（慢拖 / 快甩都不该被"拨回整月起点"）；快甩是
      一段平滑减速后停住，**到点即停、没有回弹**
- [ ] 滑行中**手指按下去**：内容立刻停在当前帧、随即跟手（不是等动画跑完才响应）
- [ ] 拖到两端（1900-01 / 2100-12）是**橡皮筋**，松手弹回（不是硬墙）
- [ ] **月份大标题与星期栏钉在顶部不动**，只是**换字**：大标题 = **占视口最多**的那一个月
- [ ] 每个月 1 号上方显示的**月份小标签**，**居中压在 1 号的正上方**（不是左对齐）
- [ ] 月份小标签紧贴在**分割线上方**（不额外占一行高度），
      与上一个月最后一行**留出一小段空档**（"以小月份的上方为限"）
- [ ] 一屏正好 **6 行 = 一个月**（行高与 iOS 同一条尺子）：6 行月正好铺满、
      5 行月底下露下个月第一行
- [ ] 年态同样跟手，相邻年份滑进来（**不应该拖出空白**）
- [ ] 周态竖直拖没有反应，横向拖才翻周；横拖时**左右邻周**都在（**不应留白**）
- [ ] 翻月之后右上胶囊从「今天」变成具体日期（如「9月26日」），点它回到今天
- [ ] 顶栏左胶囊在**月态读作「返回年历」**、周态读作「返回月历」（TalkBack）

### 1.2.2 三态切换的"从哪来到哪去"（2026-09-27 重点）

- [ ] **在半月位置**（不是整月起点）点某一天 → 进周态：那一行**平滑地**升到星期栏下方，
      其余行上/下移出屏幕，当日内容从下面顶上来
- [ ] 周态返回月态：**同一行回到它原来的位置**（月视图的滚动位置**一点都不变**）
- [ ] 月 → 年：连续流从"当前那张月网格"缩进年历卡片（**不应跳回该月静止位置**）
- [ ] 年 → 月（点迷你月）：网格从卡片长出来，**下一个月的日期立即出现**（不等动画结束）
- [ ] 反复"月→周→月→年→月"之后，月视图仍在原来的滚动位置

### 1.2.1 排版（按 iOS 参考图重排；2026-09-27 行高改为对齐 iOS）
- [ ] 行高 = `(区高 − 标题槽 − 星期栏) / 6`（iPhone 94pt / 本机 ~105dp），一屏一个月
- [ ] **农历完整可见**，没有下半截被切掉（尤其把系统字号调大之后）

### 1.3 当日内容

## 5. 日记页 · **阅读态**（2026-09-27 新增）

> 这一屏这一轮只做**阅读**：点开一天、看内容、页内搜索、多选删除。
> 编辑态（格式栏 / 图片插入 / 保存）是下一轮，**先不用报**它的排版问题。

**怎么进**：首页点某一天的「日记卡片」→ 进阅读页；或点首页「写日记」（直接进编辑态，下一轮）。

- [ ] **富文本**：大标题 28 / 小标题 22（半粗）/ 正文 16 / 引用（`surfaceContainerHigh` 浅底 + 4dp 圆角，
      **左侧有一条 4dp 竖条**，文字内缩 16dp，比正文小一级）
- [ ] **列表**：每项前是一个 8dp 圆点（标记槽 18dp + 间距 10dp → 正文从 **28dp** 起），
      **换行后的第二行也对齐 28dp**（悬挂缩进）；**待办**：18dp 勾选框（圆角 2dp、描边 2dp），
      完成的 = 品牌色实底 + 白勾 + 文字删除线 + 变灰
- [ ] **三处一致**：同一段内容在**阅读 / 编辑 / 首页日面板预览**三处，字号、行高、**段距 8dp**、
      标记缩进、引用底与竖条都对得上（编辑态的待办完成态也补上了删除线 + 变灰）
- [ ] **行内样式**：粗体 / 斜体 / 删除线 / 下划线**可叠加**（「三个一起」那一行要同时有删除线与下划线）
- [ ] **居中**段落真的居中；**图片**宽度 = 正文列宽（**编辑态同样铺满**，窄图不再按自然宽度缩小）、
      圆角、按原比例、没有高度上限
- [ ] 点图片 → **全屏预览**（黑底、适宽）；点一下或下拉关闭；**双击**在「适宽 / 原始」间切换
- [ ] **Hero 卡**（最上面那张）：日期 + 「今日」胶囊（**只有今天有**）+ 首条时间 + 「N 个片段」+ 地点
- [ ] **空的一天**：Hero 卡里写「这一天没有留下日记。」，**不是**整屏空白，顶栏仍有写入口
- [ ] **历史日期**（非今天）顶栏**没有**铅笔（写日记）图标；长按卡片会提示「只读内容」（除非在设置里打开「允许补写 / 修改历史日记」）
- [ ] **滚动时顶栏不动**（返回 / 搜索 / 写日记 / 分享始终在顶部）
- [ ] **分享长图**：地点**只到「区县」级**（设置里可改「分享位置精度」：隐藏 / 区县 / 城市 / 省份），
      **精确地点与街道在任何设置下都不出现** —— 老记录把地点名写在文本里的也一样
      （分享文案只从地区列 `country / region1..3` 重建，重建不出来就不显示地点）

**页内搜索**

- [ ] 点顶栏放大镜 → 搜索栏出现（**悬浮在内容上方**，占满宽度、圆角、有轻微阴影）
- [ ] 输入关键词 → 命中处**底色高亮**（品牌色浅底），右侧显示 `当前/总数`
- [ ] 点「⌄ 下一个匹配」：内容**跳到该命中所在的卡片**，而**搜索栏留在原处不动**、计数跟着变
- [ ] **当前命中有单独的选中样式**：被选中的那一处是深色实底（浅色主题下是品牌蓝实底白字），
      其余命中是浅底 —— 连点「下一个」时能看出换的是哪一处
- [ ] 连点到底会**从头再来**（循环）；「⌃ 上一个」同理
- [ ] 点「✕」清空关键词；再点顶栏放大镜收走搜索栏

**多选与删除**

- [ ] **长按**任意卡片 0.4 秒 → 顶栏变成「✕　已选择 1 项　🗑」
- [ ] 卡片左侧出现勾选圈；被选中的卡片有 **2dp 品牌色描边** + 实心勾
- [ ] 在多选态点其他卡片 → 勾上 / 取消；标题里的数字跟着变
- [ ] 点 🗑 → 弹「删除编辑块 · 将删除选中的 N 个编辑块」→「删除」真的删掉并回到阅读态
- [ ] **把一天删空**：停在阅读态显示空态，**不会**自动退回首页
- [ ] 多选态按系统返回键 → 先退出多选，页面不关

**进出编辑**

- [ ] 点任意卡片 → 进编辑态，且**载入的就是这一条**的内容（卡片上的时间/地点也在）
- [ ] 在编辑态**什么都不改**按返回 → 回到**同一页的阅读态**（不是回首页）
- [ ] 改几个字再按返回 → 弹「退出编辑」；选「放弃」→ 回到阅读态（内容没被改掉）

## 6. 日记页 · **编辑态**（2026-09-27 新增）

> 从阅读态**点任意卡片**进编辑（今天 / 开了「允许补写历史日记」的日子才能改）。
> 这一节按"按钮行为"分组，**第 2 ~ 4 组是本轮（2026-09-28 返工）的重点**：
> 段落格式六选一互斥、居中与空行的规则、回车行为，都按用户逐条定稿的口径改过
> （口径见 `04-diary.md` §3.3 的"按钮功能规则"表），每个按钮都请单独试一次。
>
> 🤖 **其中 12 条已经自动化了**：`python3 tools/dev_format_rules.py`（真机连着就能跑，
> 坐标从 uiautomator 语义树取、光标用帧差定位，逐条打印期望值/实测值）。
> 下面这份清单留给"机器判不了"的部分：手感、外观、以及自动化没覆盖的组合。

**1. 版面与键盘**

- [ ] 顶栏右侧是三个动作：**插图 · 放弃修改 · 保存**（保存是品牌色实心勾）
- [ ] 顶部是时间胶囊（`auto_time` 关掉时不显示）+ 地点行；下面就是正文，**编辑时的字号与阅读态一致**
      （大标题明显更大、引用更小）
- [ ] 点正文区 → 键盘弹起，**底部格式栏正好贴在键盘上方**，9 个按钮**一行放得下**（窄机可横向滑动，不折行）
- [ ] 打字 / 回车 / 换行时**光标永远不会被格式栏或键盘挡住**
- [ ] 点卡片内的空白处、或点顶栏空白处 → 键盘收起；**点格式栏按钮不会收键盘**

**2. 段落样式与标记（六选一，互斥）**

> 用户 2026-09-28 定稿的规则 2 / 3 / 5：大标题 / 小标题 / 正文 / 引用 / 列表 / 待办
> **同时只有一个**，启用一个会自动取消另外的（实现上是"先把本行格式清回正文，再套上你点的那个"）。

- [ ] 点最左边的 `T▾` → 弹出菜单：**大标题 / 小标题 / 正文**（当前项打勾），**引用不在菜单里**
- [ ] 选「大标题」→ 当前**整段**变大（不是整篇）；**光标也跟着变成大标题那么高**
- [ ] 在**空行**上先选「大标题」再打字 → 打出来的就是大标题；改选「引用」→ 光标变矮（引用字号更小）
- [ ] 互斥：列表行点「大标题」→ **项目符号消失**、字变大；大标题行点「待办」→ 字回正文大小、行首出现勾选框
- [ ] 选几行再点「列表」→ 这几行都变成列表项；再点一次 → 取消。
      **注意：取消只影响你选中的这些行**，别的行一个都不动
- [ ] 列表 / 待办的项**很长折成两行**时，第二行**对齐到正文起点**（28dp），不会顶到圆点 / 勾选框底下
- [ ] 行首的**待办勾选框**对 M3：18dp、**圆角 2dp**、未选是 2dp 灰描边、选中是品牌色实底 + 白勾；
      勾上之后**文字有删除线并变灰**（与阅读态一致），再点一下能退回来
- [ ] 「引用」按钮：整段出现一块**圆角浅底** + **左侧一条 4dp 竖条**（与阅读态、首页预览同参数），
      文字内缩 16dp；**在空行上点也有底**（那是"接下来输入的就是引用"）
- [ ] 「引用」**不会**点亮最左边的段落样式按钮（引用有自己的按钮；引用行上段落样式菜单里显示「正文」）
- [ ] 列表 / 引用 / 待办 / **图片行**上，「居中」按钮是**灰的、点不动**（规则 5）；换回正文行 → 又能点了

**3. 居中（规则 4）**

- [ ] 有内容的行点「居中」→ **整行**居中；再点一次 → 回到左对齐
- [ ] 居中**只作用于光标那一行**；**回车的下一行是左对齐**（不会把居中带下去）
- [ ] **空行**点「居中」→ **光标跑到这一行的中间**；再点一次 → 光标回到最左边
- [ ] 居中的行再点「列表」→ 自动取消居中（居中按钮同时变灰）；
      **再取消列表，居中不会自己回来**（要重新点「居中」）

**4. 回车（规则 3 / 4）**

- [ ] 列表 / 待办项里回车 → **另起一项**（新行带同样的圆点 / 勾选框）
- [ ] 在**空**的列表项上再回车 → **结束列表**（标记消失，回到普通空行）
- [ ] 标题行回车 → **下一行还是标题**（段落格式随换行延续）；引用行回车 → 下一行还是引用
- [ ] **空的引用行**上回车 → 没有新行，而且**引用结束**（「引用」按钮灭掉、底色消失）
- [ ] 正文回车 → 新行是普通空行；**再敲几次回车也都可以**（不居中的空行不限制，想留几个空行就留几个）
- [ ] **居中的空行**上回车 → **没有反应**（居中的时候不让有空行；先把居中取消就又能换行了）

**5. 行内样式（B / I / S / U —— 这是最容易做错的一组）**

- [ ] **只放光标（不选字）**点 B → B 按钮亮起；**接着打字，新字是粗体**，已经写好的字**一个都没变**
- [ ] 光标点到一段粗体字的**后面** → B 自动亮起（接着打字还是粗体）
- [ ] **选一段字**再点 B → 整段变粗；再点一次 → 整段取消（不会变成"补丁"）
- [ ] 选一段**混合**（一半粗一半不粗）再点 B → 整段统一变粗（而不是取反）
- [ ] I / S / U 同上；**四种可以同时亮、同时生效**（粗 + 斜 + 删除线 + 下划线叠在同一段字上）
- [ ] 把一行的文字**删光再输入** → 段落样式还在（比如大标题删光再打字，还是大标题）

**6. 退出与保存**

- [ ] 什么都不改直接点「放弃修改」→ **不弹窗**（本来就没改）
- [ ] 改了字点「放弃修改」→ 弹「放弃修改？ / 未保存的内容将丢失，且无法恢复。」→ 点「放弃」→
      **内容回到刚进来时的样子，页面仍停在编辑态**
- [ ] 改了字按**返回**（或顶栏 ←）→ 弹「退出编辑 / 内容尚未保存，退出前需要处理。」→
      「放弃」回到**本页阅读态**（不是回首页）
- [ ] 点 **保存（✓）** → 回到阅读态，**刚写的内容就在页面上**（大标题/列表/待办/加粗都在）
- [ ] 保存之后**键盘自动收起**
- [ ] 新建片段（今天页的铅笔）在还没定位到地点时保存 → 弹「未获取到位置 / 仍然保存」
